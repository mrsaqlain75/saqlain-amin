What I build

End-to-end systems, one mind across the stack

Most projects I take on need every layer built and owned by one engineer — so there are no handoffs and nothing falls between the cracks:

  • Web applications — dashboards, booking systems, admin panels, client portals and marketing sites built with React and Next.js.
  • APIs & back ends — REST APIs, authentication, payments, file handling and scheduled jobs on Node.js and Express, with Prisma over PostgreSQL or MySQL, or MongoDB.
  • Mobile apps — cross-platform apps with React Native and Capacitor, and native Android in Kotlin / Java.
  • Deployment & handover — CI/CD, hosting on Vercel / Railway / AWS, and training your team to run the admin side without a developer.

How it works

From first message to launch

  1. Scope call — we talk through the problem, users and constraints, and agree on what “done” means.
  2. Proposal — a fixed scope, timeline and price, or a weekly rate for open-ended work.
  3. Build in the open — a staging URL from day one, short updates, and a demo at the end of each milestone.
  4. Launch & handover — deployment, documentation and a walkthrough so your team can run it.
  5. Support — a maintenance retainer if you want ongoing changes and monitoring.
